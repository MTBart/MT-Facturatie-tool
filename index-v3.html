⚠ Tokens worden opgeslagen in localStorage van je browser — niet in de code. Zie instructies hieronder voor de Cloudflare Worker instelling.

Cloudflare Worker — token beveiliging

De Claude API key staat al veilig in de Worker als Secret CLAUDE_KEY.
Verplaats ook het Moneybird token naar de Worker:

1. Ga naar Cloudflare Dashboard → Workers → mt-claude-proxy
2. Tab Settings → Variables → Add variable
3. Naam: MB_TOKEN, waarde: je Moneybird token, aanvinken als Secret
4. Pas de Worker code aan zodat hij env.MB_TOKEN gebruikt i.p.v. de token uit de query parameter
